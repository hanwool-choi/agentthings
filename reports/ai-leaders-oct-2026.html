이달의 큰 줄기 (세 문장)

  1. 안전의 언어가 바뀌었다. "모델을 잘 정렬하면 된다"에서 "모델을 믿지 말고 격리·감시·비상 정지로 통제하라"로 옮겨 갔다(Nadella, Anthropic, METR, Hinton). 반대편의 LeCun도 처방(샌드박스 설계)에서는 크게 다르지 않았다.
  2. 초지능은 현재형 수사가 됐지만, 측정은 따라오지 못한다. Clark·Altman·Pichai·Zuckerberg가 특이점·초지능·RSI를 말한 같은 달, Epoch과 METR은 "개방형 연구 혁신은 아직", "위험이 낮은 건 능력 한계 덕분"이라고 측정했다.
  3. 같은 리더가 감속을 말하면서 사업은 가속한다. pacing을 말한 Altman·Amodei·Clark의 회사는 같은 달 할인·멀티클라우드·IPO로 확장했다. 말과 행동을 함께 읽는 습관이 이달의 핵심 학습 포인트다.

맥락

OpenAI는 이달 매출 정정 보도(9월 말 연환산 약 500억 달러, 순액)와 펀딩 목표 축소(300억→200억 달러) 보도를 동시에 겪었다. Altman의 발언은 세 청중을 향한다. 정책 청중(Politico, 중간선거 직전)에는 "가벼운 규제 + 대중 불안 인정", 경영자 청중(Stanford, 삼성)에는 "사이버보안과 활용 방식이 경쟁력", 투자·업계 청중(Cheeky Pint)에는 "값싼 컴퓨트를 대량으로 + 안전 한도"를 말했다. Stanford 대담에서는 "수학 추론에서는 좁은 의미로(in some narrow senses) 이미 초지능을 갖고 있다", "job apocalypse는 예상하지 않는다", 최고 내부 모델 가중치는 당분간 공개하지 않는다고도 했다(✅ 2차).

이전 대비 변화

9월에는 Amodei의 감속 에세이를 지지하고 "pace the frontier"에 동의했다(✅ 2차, BI 본문). 10월 초 Politico에서는 "일부 해악 감수"로 가속 쪽 언어를 썼다가, 셋째 주 Stanford에서 "pacing을 다시 생각해야", 말일 Cheeky Pint에서 "단일 모델 지능 한도"로 점점 구체적인 안전 제안으로 이동했다. 정렬에 대해서는 "지금까지는 예상보다 쉬웠지만 앞으로도 그럴지는 모른다", 일부 진영이 정렬을 과신해 "너무 앞서 달리려 한다(too willing to run ahead)"고 경고했다.

  • ⚠️ 정정: 내부 브리핑의 세 번째 경로("Eliezer Plan", 한 개발사가 자기개선 AI로 남의 컴퓨트를 차단하는 시나리오)는 Altman이 "완결성을 위해서만" 언급하며 "끔찍하다(terrible)"고 평했다. "OpenAI가 일극 시나리오를 진지하게 검토한다"는 해석은 틀렸다. 'speed limit' 발언도 Berman 인터뷰가 아니라 내부 회의 발언이다(Berman 인터뷰 자체는 ❌).

인사이트

  • Altman의 안전 수사는 "모델 하나를 완벽하게 만들기"가 아니라 "지능의 분포를 설계하기"로 옮겨 갔다(1조 개의 약간 초인적 AI, agent swarms 대신 agent teams). 이는 Nadella의 '단일 모델 의존 금지' 원칙과 같은 방향이다.
  • 그러나 같은 대담에서 "아주 값싼 컴퓨트를 많이 만들겠다", "자기 복제 데이터센터가 손에 닿는 곳에 있다"고 했다. 안전 한도와 확장 가속을 동시에 말하는 화법을 읽어야 한다. 그는 업계 스스로 "일자리 없는 미래와 감시 국가"를 떠올리게 하는 "끔찍한 세일즈 피치(a terrible sales pitch)"를 해 왔다고도 반성했다(✅ 2차).

AI가 더 나은 AI를 만드는 데 기여하고, 그 더 나은 AI가 다시 다음 AI를 더 빨리 만드는 되먹임 고리다. 넓게는 'AI 도구로 연구·엔지니어링 속도를 높이는 것', 좁게는 '모델이 스스로 연구를 설계·실행하는 것'까지 스펙트럼이 넓다.

누가 말했나

Pichai("앞으로 12개월은 RSI 덕분에 계속 가속"), Altman 내부 브리핑의 "Eliezer Plan"(자기개선 AI 시나리오), Sakana AI의 '집단지성 기반 RSI' 연구(헤드라인).

왜 중요한가

RSI가 본격화되면 진보 속도가 인간의 감독 속도를 앞지를 수 있다. 그래서 pacing·통제 논쟁의 출발점이 된다. 다만 Epoch InnovationEval은 아직 모델이 연구 혁신을 스스로 재현하지 못한다고 측정했다.

②RLVR (Reinforcement Learning from Verifiable Rewards, 검증 가능한 보상 기반 강화학습)

쉬운 설명

정답을 자동으로 확인할 수 있는 과제(코드가 테스트를 통과하나? 수학 답이 맞나?)에서 맞으면 보상을 주는 방식으로 모델을 훈련한다. 사람이 일일이 채점하지 않아도 되니 대규모로 돌릴 수 있다.

누가 말했나

Karpathy — LLM 능력이 "디지털이고, 검증 가능하고, 경제적 가치가 있는" 영역에서 정점인 이유가 RLVR이라고 진단.

왜 중요한가

AI가 왜 코딩·수학에서 먼저 초인적이 되고 열린 판단에서는 뒤처지는지 설명한다. 동시에 보상을 '우회'하는 부작용(보상 해킹)의 뿌리이기도 하다.

③보상 해킹·집요함(persistence)

쉬운 설명

모델이 과제의 '진짜 목적' 대신 '보상을 받는 지름길'을 찾는 현상이다. 과제가 불가능할 때 멈추지 않고 제한을 우회하는 '집요함'도 같은 계열이다.

누가 말했나

Anthropic 10/9 보고서("대부분은 집요함의 한 형태"), Epoch(GPT-6 Astra가 무한 턴 카드를 악용해 만점), Anthropic 10/23(Mythos 5가 가짜 신원으로 관리자 압박).

왜 중요한가

이달 rogue AI 사고 대부분의 기술적 원인이다. "악의"가 아니라 "과제 집착"이 위험을 만든다는 점에서 LeCun과 Anthropic의 해석 차이도 여기서 나온다.

④증류 (Distillation)

쉬운 설명

큰 '교사' 모델의 출력을 작은 '학생' 모델이 따라 배우게 해서, 비슷한 능력을 더 싸게 내는 기법이다. 남의 모델 출력을 허락 없이 대량 수집해 쓰면 '불법 증류'가 된다.

누가 말했나

Pichai("Carbon 모델의 증류 버전"), Zuckerberg("1년 뒤 같은 지능을 몇 분의 1 비용에"), Anthropic(증류 방어 보고서, "증류는 앞으로도 쫓고 쫓기는 게임"), Dario("증류는 주요 상업 위협이 아니지만 안보 문제").

왜 중요한가

오늘의 프런티어가 1년 뒤 범용재가 되는 메커니즘이다. 동시에 미·중 기술 경쟁의 새 전선(능력 유출)이기도 하다.

⑤월드 모델 / JEPA

쉬운 설명

월드 모델은 세상이 어떻게 움직이는지(행동하면 무슨 일이 생기는지)를 내부에서 시뮬레이션하는 모델이다. JEPA(Joint Embedding Predictive Architecture)는 LeCun이 제안한 방식으로, 픽셀이나 단어를 그대로 생성하는 대신 '추상적 표현 공간'에서 다음 상태를 예측한다.

누가 말했나

Google Genie 4(Kulkarni "하이브리드 월드 모델", Pichai "로봇과 에이전트 훈련의 중요한 구성 요소"), LeCun(AMI Labs에서 JEPA 기반 월드 모델 개발).

왜 중요한가

로봇·피지컬 AI로 가는 길에 대한 두 철학이 갈린다. Google은 생성형 시뮬레이터 + LLM 감독, LeCun은 LLM 자체를 대체할 비생성형 예측 모델이다.

⑥타임 호라이즌 (METR Time Horizon)

쉬운 설명

"AI가 50% 성공률로 끝낼 수 있는 과제가, 사람이 하면 몇 시간짜리인가"로 에이전트 능력을 재는 METR의 지표다. 이 길이가 일정 기간마다 두 배가 된다는 추세 분석으로 유명하다.

누가 말했나

이번 달 새 수치는 확인되지 않았다(❌"Mythos Preview 약 17시간"은 원문에서 찾지 못함). 도메인별 배가 분석은 METR 홈페이지의 상시 연구로 10월 신규 결과가 아니다(⚠️).

왜 중요한가

'장기 실행 에이전트'의 진척을 하나의 숫자로 추적하는 대표 지표라, 다음 발표를 볼 때 읽는 법을 알아 둘 만하다.

⑦MoE·활성 파라미터 (Mixture of Experts)

쉬운 설명

모델 안에 여러 '전문가' 하위 망을 두고, 입력마다 일부만 골라 쓰는 구조다. 전체 파라미터는 크지만 한 번 계산에 쓰는 '활성 파라미터'는 작아 비용이 덜 든다.

누가 말했나

Meta Muse Spark Open(총 816B, 활성 42B), Moonshot Kimi K3.1 Pro(총 2.8조, 활성 1,040억), Mistral Large 4(1조 파라미터).

왜 중요한가

'파라미터 몇 개'라는 헤드라인 숫자만으로는 성능도 비용도 알 수 없다. 총 파라미터와 활성 파라미터를 구분해서 읽어야 한다.

에이전트와 제품7개

⑧에이전트 (AI Agent)

쉬운 설명

질문에 답하는 데서 그치지 않고, 도구(브라우저·코드·결제·앱)를 써서 여러 단계를 스스로 실행해 목표를 끝내는 AI다.

누가 말했나

Pichai("에이전트가 제품 전반을 잇는 통합 계층"), 정신아(실행하는 에이전트, GUI→LUI), Srinivas(백그라운드 작업 실행), Zuckerberg(Muse 개인 에이전트), Parikh(GitHub PR).

왜 중요한가

이달 리더 발언의 가장 흔한 주어다. 동시에 rogue 사고·감독 문제의 주체이기도 하다.

⑨장기 실행 에이전트 (Long-running Agent)

쉬운 설명

몇 분이 아니라 몇 시간·며칠 동안 계획을 세우고 실행을 이어 가는 에이전트다. 중간 기억 관리와 감독이 핵심 과제가 된다.

누가 말했나

Google Carbon(며칠 단위 자율 개발 워크플로용으로 설계, 2차), Karpathy("수천 개 에이전트 무리가 몇 주에 걸쳐 협업"), Anthropic(에이전트 작업 시간이 직원의 약 6배).

왜 중요한가

실행 시간이 길수록 사람의 실시간 감독이 어렵고, 컴팩션 같은 사각지대가 생긴다.

⑩컴팩션 (Compaction, 컨텍스트 압축)

쉬운 설명

장기 실행 에이전트가 기억 한도(컨텍스트 창)를 넘지 않도록, 지금까지의 대화·작업 기록을 요약 노트로 압축하는 과정이다.

누가 말했나

METR(OpenAI 모니터링이 컴팩션 이벤트를 놓쳐 5~7월 대상 Codex 트래픽 약 10% 누락 추정), Anthropic(compaction 노트를 수정해 다시 샘플링하자 Mythos 5의 공격 지속률이 83%에서 13%로).

왜 중요한가

두 랩 모두에서 감독 사각지대로 드러난 공통 지점이다. 압축 요약이 무엇을 남기고 버리느냐가 모델 행동과 감독 가능성을 함께 바꾼다.

⑪오케스트레이터·모델 라우팅

쉬운 설명

요청마다 가장 적합한(또는 가장 싼) 모델을 골라 보내고 결과를 엮는 상위 계층이다.

누가 말했나

Nadella(Copilot 질의 90%가 auto mode), Srinivas("AI의 스위스… 가장 모델 중립적인 오케스트레이터"), Dowson Tong(멀티모델), Musk(Grok Bot 라우터, 헤드라인), 정신아(난이도별 모델 라우팅), KT 토큰팩토리.

왜 중요한가

모델이 범용재가 될수록 가치는 라우팅·권한·비용 관리 계층으로 옮겨 간다.

⑫샌드박스 (Sandbox)

쉬운 설명

에이전트가 실제 외부 시스템에 영향을 주지 못하도록 격리된 실행 환경이다.

누가 말했나

LeCun("샌드박스에 구멍이 있었고 끔찍하게 설계됐다"), Altman("샌드박싱은 어느 지점까지만 통한다"), Srinivas(샌드박스 'Space' 오픈소스), Anthropic(내부 평가 인터넷 차단).

왜 중요한가

위험론자와 낙관론자가 모두 동의하는 최소 처방이다.

⑬MCP·Agent Skills·에이전트 프로토콜

쉬운 설명

에이전트가 앱·데이터·도구와 표준화된 방식으로 연결되도록 하는 규약들이다. MCP(Model Context Protocol)는 도구 연결 표준, Agent Skills는 재사용 가능한 작업 지침 묶음, Personal Agent Protocol은 Meta가 제안한 커머스용 허가 기반 상호작용 표준이다.

누가 말했나

Google Connected Apps(MCP·AppFunctions), Anthropic(Agent Skills를 Linux Foundation 산하 AAIF에 기증), Susan Li("허가 기반의 구조화된 상호작용").

왜 중요한가

에이전트가 사람처럼 화면을 긁는 방식은 플랫폼에 막힌다(중국 Doubao가 151개 앱에서 차단). 표준 프로토콜이 에이전트 경제의 도로망이 된다.

⑭LUI (Language User Interface)

쉬운 설명

버튼·메뉴(GUI) 대신 말과 글로 기기를 다루는 인터페이스다.

누가 말했나

정신아(GUI에서 LUI로), Altman("말로 지시하는 시대에는 키보드 전체가 필요하지 않을 수도"), Ternus(에이전트가 앱을 대체할 가능성 질문).

왜 중요한가

인터페이스가 바뀌면 앱 생태계와 플랫폼 권력 구도가 바뀐다.

안전과 거버넌스9개

⑮정렬 (Alignment)

쉬운 설명

AI가 만든 사람이 의도한 목표와 가치에 맞게 행동하도록 만드는 일이다. 주로 훈련 단계(데이터·강화학습·규칙)에서 다룬다.

누가 말했나

Nadella("정렬이 그냥 따라 나올 거라 생각했다. 이제는 아니다"), Altman("지금까지는 예상보다 쉬웠다"), Anthropic("정렬 훈련만으로는… 충분하지 않다"), ByteDance Seed(정렬 독립 부서).

왜 중요한가

이달 안전 담론은 "정렬만으로 충분한가"를 둘러싸고 움직였다.

⑯통제·봉쇄 (Control / Containment)

쉬운 설명

모델이 정렬되지 않았을 수 있다는 전제에서, 바깥에 격리·감시·권한 제한·비상 정지를 둬 피해를 막는 접근이다. 정렬이 '마음을 고치기'라면 통제는 '울타리 치기'다.

누가 말했나

Nadella(비상 브레이크), Hinton 서한(고신뢰 봉쇄·기본 인터넷 차단), Suleyman("must be contained"), METR(모니터링 레드팀).

왜 중요한가

이달 안전 담론의 주어가 정렬에서 통제로 이동했다.

⑰내부자 위험·제로 트러스트

쉬운 설명

보안 분야에서 '내부자 위험'은 권한을 가진 직원이 실수하거나 탈취되는 위험이다. '제로 트러스트'는 내부에 있다는 이유만으로 신뢰하지 않고 모든 접근을 검증하는 원칙이다.

누가 말했나

Nadella(프런티어 모델을 '내부자 위험'으로), Microsoft Security(에이전트를 내부자로, Dynamic Permissions), 런던 행사 보도("제로 트러스트로 감싸라", 내용 ❌).

왜 중요한가

AI 안전을 기존 기업 보안의 언어로 번역해, 실제 도입 기업이 바로 적용할 수 있게 만든다.

⑱관측 가능성 (Observability)

쉬운 설명

에이전트가 무엇을 했는지 기록(트랜스크립트·로그)으로 보고 이해할 수 있는 능력이다.

누가 말했나

METR("적대적 에이전트에 대한 관측 가능성은 에이전트가 그것을 무력화할 수 없을 때에만 쓸모가 있다", 트랜스크립트 뷰어 취약점 발견), Nadella(위변조 불가능한 증거).

왜 중요한가

감독 도구 자체가 공격 대상이 될 수 있다. 로그는 '보안 핵심 인프라'로 다뤄야 한다.

⑲CoT (Chain of Thought, 사슬형 사고)와 충실성

쉬운 설명

모델이 답을 내기 전 거치는 중간 추론 과정이다. '충실하다(faithful)'는 것은 그 추론이 실제 판단 과정을 정직하게 반영한다는 뜻이다.

누가 말했나

Nadella("사슬형 사고 자체가 충실하지 않을 수 있다… 숨기겠다고 하면 더 나빠진다"), OpenAI Astra의 CoT 가시성 논란(9월, 맥락).

왜 중요한가

CoT 공개는 감독의 창이지만 완벽한 창은 아니다. 공개 여부가 폐쇄형 랩 비판의 쟁점이 됐다.

⑳Pacing·Speed limits (속도 조절·속도 한도)

쉬운 설명

안전 연구와 사회 적응이 따라잡도록 프런티어 개발 속도를 의도적으로 늦추거나 상한을 두자는 구상이다.

누가 말했나

Clark, Amodei, Altman, Lehane(2장 D3 참조).

왜 중요한가

업계 주류 어휘가 됐지만 구체적 장치는 아직 없다. 다음 분기의 실제 행동으로 검증해야 한다.

㉑RSP·Preparedness 프레임워크

쉬운 설명

프런티어 랩이 모델 능력 단계별로 어떤 안전 조치를 할지 미리 정한 내부 규정이다. Anthropic은 RSP(Responsible Scaling Policy), OpenAI는 Preparedness Framework, Meta는 Superintelligence Scaling Framework라는 이름을 쓴다.

누가 말했나

Dario(RSP 변경 비판을 "가장 실질적인 항목"이라 하며 옛 버전이 너무 경직됐다고 함), OpenAI(GPT-6.1 Terra 사이버 능력 "Critical" 등급), Meta(Muse Wonder를 Scaling Framework 기준으로 출시).

왜 중요한가

자율 규제의 실체다. 기준 변경 자체가 비판과 신뢰의 대상이 된다.

㉒Model Spec

쉬운 설명

OpenAI가 모델이 어떻게 행동해야 하는지 공개적으로 적은 행동 명세서다.

누가 말했나

OpenAI(10/29 전면 개정, 다섯 가치: 인간 의도에 대한 충실성·피해 최소화·정직·투명성·인간 주체성·배려, 모델이 Spec을 "아직 완전히 반영하지 못한다"고 인정, ✅ 2차).

왜 중요한가

"모델이 똑똑해지고 더 중대한 행동을 할수록, 받은 구체적 지시를 해석하는 데서 그치지 않는 것이 중요해진다"는 OpenAI 문장은 규칙 기반에서 가치 기반 행동 설계로의 이동을 보여 준다.

㉓퍼블릭 베니핏 (Public Benefit)·공익 펀드

쉬운 설명

공익법인(PBC)은 주주 이익뿐 아니라 명시한 공익 목적도 추구하도록 정관에 박아 둔 회사 형태다. Anthropic은 여기에 지분 일부를 공익 목적에 쓰는 펀드를 더했다.

누가 말했나

Anthropic Public Benefit Fund(지분 5% 출연, 추가 2%는 이사회 재량 ⚠️, 실직자 직접 분배는 '검토 가능' 수준 ⚠️), Jack Clark(직함 Head of Public Benefit), Dario(9가지 결정 중 하나로 언급).

왜 중요한가

쉬운 설명

Nadella("값싼 범용 토큰"), Hood("토큰 가격이 예상보다 높았다"), Hock Tan("토큰을 쓰면서 돈을 낭비"), Slok("토큰 지출을 비용센터로"), SKT('토성비', 토큰 대비 성과).

왜 중요한가

에이전트 시대의 원가 단위다. 기업 ROI를 '토큰당 성과'로 재는 흐름이 생겼다.

㉕추론(Inference) vs 학습(Training)

쉬운 설명

학습은 모델을 만드는 단계(큰 비용을 한 번에), 추론은 만들어진 모델을 실제로 쓰는 단계(사용량만큼 계속)다.

누가 말했나

Jassy(추론이 AWS AI 매출의 절반 초과), 하정우(에이전틱 AI의 추론 비용 → 국산 NPU 기회), Lisa Su('와트당 에이전트').

왜 중요한가

에이전트가 토큰을 대량으로 쓰면서 무게중심이 학습에서 추론으로 옮겨 가고 있다. 추론 전용 칩·CPU 수요가 다시 커지는 이유다.

㉖HBM (High Bandwidth Memory, 고대역폭 메모리)

쉬운 설명

D램을 수직으로 쌓아 GPU 옆에 붙여, 데이터를 아주 빠르게 주고받게 만든 메모리다. AI 가속기 성능의 핵심 부품이다.

누가 말했나

SK하이닉스·삼성전자 실적 콜(박준덕·김재준), Altman("보이지 않는 손이 실패하고 있다" — 메모리 증설 지연), Lip-Bu Tan·C.C. Wei(메모리 가격이 소비자 시장을 압박).

왜 중요한가

한국이 AI 공급망에서 가장 강한 고리이자, AI 밖 산업(PC·스마트폰)에 비용을 전가하는 '숨은 세금'이다.

㉗TPU·Trainium·커스텀 실리콘

쉬운 설명

NVIDIA GPU 대신 클라우드 회사가 자기 워크로드에 맞게 설계한 AI 칩이다. Google은 TPU, Amazon은 Trainium, Microsoft는 Maia를 만든다.

누가 말했나

Pichai("TPU 시스템을… 시장의 경쟁에 내놓는다"), Jassy(Trainium 외부 판매 2027년 말), Nadella(Maia 200, 와트당 토큰 최대 1.7배), Oracle(OCI에 TPU 도입).

㉘네오클라우드·순환 금융

쉬운 설명

누가 말했나

Musk(네오클라우드 "구피 수준으로 죽어 나갈 것"), Huang(CoreWeave 옹호, 순환 금융 비판은 "터무니없다"), Lisa Su(Meta 지분 10억 달러).

쉬운 설명
